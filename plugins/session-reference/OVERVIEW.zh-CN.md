# 会话引用

把已有会话引用到新输入框，让 agent 按需读取历史并继续任务。在原生附件菜单选择“引用会话”，找到来源会话，再填写“继续完成剩余测试”等要求并正常发送。

附件仅携带简短引用。agent 可以读取概览、翻阅旧消息、搜索关键内容，以及分段读取长消息。概览由原文摘录组成，不是 AI 生成的完整交接摘要；插件不会额外调用模型生成摘要。

daemon 和客户端均需使用 Paseo 0.16.2 起的 0.16.x 版本，或 0.17.4 起的 0.17.x 版本。来源必须属于当前输入框所在主机，并且历史可读。选择器按标题、目录和 ID 搜索最近更新的 2,000 个可见会话，包含归档会话，最多返回 12 个候选。没有历史的会话不显示；部分历史读取失败时显示其他结果，全部读取失败时显示错误。

引用在搜索结果生成时记录主机、会话、历史版本和截止位置，不包含之后的新消息。历史重置、来源删除或截止条目变化后，需要重新添加引用。只要来源历史仍然有效，插件重载后仍可使用引用；引用不是历史备份。

历史由来源 daemon 保存，仅在工具请求时返回必要内容。返回的摘录会进入接收 agent 的上下文，并由该 agent 选用的 provider 处理。工具调用详情默认排除，可以按需读取；推理记录和其他插件的时间线条目不提供。不需要额外账号、连接配置或单独保存历史数据库。

引用不会停止旧 agent、复制文件、切换分支或清空已有上下文。请在新会话中使用以减少累积的 context；实际节省取决于后续读取量。provider 需要允许 Paseo 插件工具，工具不可用时，仅凭引用无法恢复旧任务内容。
