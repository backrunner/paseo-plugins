# Session Reference 0.1.1

在新会话输入框的附件菜单中选择 **引用会话**，按标题、工作目录或会话 ID 搜索来源，选择后填写“接续这个会话，完成剩余测试”等当前要求，正常发送。客户端会显示原生附件标签。仅选择附件不会发送消息或创建 agent。

客户端和 daemon 支持 Paseo 0.16.2 起的 0.16.x 版本，以及 0.17.4 起的 0.17.x 版本。它使用原生附件来源、插件 RPC、会话打开 hook 和 agent 工具。中英文菜单由宿主翻译系统显示，附件菜单由宿主统一加 `Attach` 前缀。

选择器保留原生控件和主题：长标题压缩为单行，短编号用于区分同名会话；辅助信息使用项目目录名、本地语言的简短时间及归档状态，不展示完整路径和原始时间戳。显示标题的缩短不改变引用说明里的来源信息。空间不足时辅助信息由宿主省略。`Attach`、`Searching...` 和 `No results` 是宿主文案。

## 读取方式

- 附件约携带一份简短说明、来源元数据和引用 token，不包含历史正文。
- `session_reference_read` 默认返回原始请求候选与最近的最多 8 条可读记录。最近摘录总量不超过 6,000 个 UTF-16 字符，原始请求摘录最多另加 1,200 字符。最多扫描 150 个投影条目，包含明确的截断标记和旧页游标。
- `view: "page"` 搭配 `beforeSeq` 翻阅旧记录；`view: "entry"` 搭配 `entrySeq`、`offset` 分段读取完整条目，每段最多 6,000 字符。
- `session_reference_search` 做不区分大小写的字面搜索，每次最多扫描 300 个投影条目、返回 10 段各不超过 500 字符的摘录。非空 `nextBeforeSeq` 代表还有历史未搜索；局部无结果不等于整个会话无结果。
- 工具调用及结果需显式设置 `includeTools`。推理、其他插件行和通知不会作为正文返回。

概览是原文摘录，不是完整交接摘要，不推断任务完成情况，也不额外启动模型总结。新的 agent 必须以当前用户请求为准，需要时继续查询早期约束、决定和验证证据，并检查实际工作目录、分支及文件状态。

## 引用边界

引用 token 保存主机 ID、agent ID、历史 epoch、截止序号、锚点起始序号和锚点内容 SHA-256。token 是可验证的定位信息，不是凭据，也不是安全访问令牌。历史仍由当前宿主现有的访问权限控制。

截止位置在附件搜索结果生成时确定，不会在发送时重新更新。如果需要最新进度，请移除后重新选择。模型读取时核对主机、epoch、锚点及每个返回条目的截止位置；跨主机、来源删除、重置、缺页、边界内容变化均返回错误，不偷偷切换来源或恢复最新历史。

插件读取 projected 时间线，按 `seqStart` 翻页、按 `seqEnd` 校验截止位置，避免合并后的长回复重复或越界。运行中的回复、跨越截止位置的工具结果可能导致引用失效，此时应等待来源回合结束后重新选择。

会话选择器查询同一主机最近更新的最多 2,000 个可见会话，包含归档会话；默认不包含后台助手。匹配标题、目录和 ID，最多取 12 个候选，并以每批 3 个读取尾部边界。没有历史的候选不显示；部分读取失败时保留其他结果，全部失败时显示错误。插件没有单独保存完整历史，没有模型凭据或额外连接设置。

新会话才能减少既有上下文负担。已经读取的摘录仍占用接收 agent 的 context，并交给该 agent 的 provider 处理。插件不停止来源 agent，不复制文件或切换分支。引用不能替代来源历史备份；来源不可用时，引用也无法恢复内容。provider 必须允许 Paseo 插件工具。

## 开发与安装

```sh
pnpm install --frozen-lockfile
pnpm verify:reference
paseo plugin install /absolute/path/to/paseo-plugins/plugins/session-reference
# 修改代码并验证后
paseo plugin reload session-reference
```

安装与更新仅针对这个插件，不需要重启 daemon。插件总开关须事先开启。会话打开 hook 的安装或重载会让已有 provider session 标记为 stale，宿主在下次空闲发送前重新打开；不会主动中断正在执行的回合。切勿为应用工具注入而手动 reload 正在运行的 agent。

可用对应版本的官方源码做独立编译检查：

```sh
node scripts/check-upstream-compiler.mjs \
  --source /absolute/path/to/paseo-v0.17.4 \
  --plugin /absolute/path/to/paseo-plugins/plugins/session-reference
```

显式选择本机宿主与一个空闲来源会话，执行真实只读功能检查：

```sh
pnpm check:reference-live --home /absolute/path/to/paseo-home --query title-or-directory
```

此脚本核对宿主身份与版本，调用已安装插件的搜索 RPC，并以本地编译的同一组工具处理器读取真实 SDK 历史。Paseo 将所有插件 RPC 调用归为 `daemon.manage`，所以检查连接需要该权限；脚本不调用管理或写入操作，不打印凭据和正文，不发送模型消息，也不创建 agent。它不证明 provider 已实际调用这些工具。
